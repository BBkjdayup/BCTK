# TK试题题库 Windows 桌面软件

面向教师的本地题库与组卷工具，使用 **Vue 3 + TypeScript + Tauri 2 + Rust + SQLite**，以 **MIT 许可证**开放源码。

本仓库以 **v0.1.83** 为初始源码版本，包含桌面客户端、官网、数据库迁移、测试及授权工具源码。独立云服务端、用户题库和发布签名私钥不在此仓库中。现有试用与桌面授权逻辑仍然保留，源码许可与已发布程序的功能状态分别说明，见[开源范围与构建说明](docs/open-source.md)。

- [参与贡献](CONTRIBUTING.md) · [报告安全问题](SECURITY.md) · [MIT 许可证](LICENSE) · [第三方许可](THIRD_PARTY_NOTICES.md)

这是一个面向教师个人和教育机构、以本地离线数据为核心的题库与组卷软件。题目录入、管理、组卷、文档导入导出、备份恢复和统计都可在本机完成。Windows 客户端支持教师账号和按账号隔离的题目云同步；桌面离线授权与云同步授权相互独立，网页版仍属于后续开发范围。

面向非技术人员的选型、原理和取舍说明见 [`docs/技术方案说明.md`](docs/技术方案说明.md)。

## 当前技术方案（Tiptap + SQLite + canvas-editor + Rust OOXML）

- **Tauri 2**：把网页界面包装成 Windows 桌面程序。它使用系统自带的 WebView2 显示界面，比 Electron 安装包更小、内存占用通常也更低。
- **Vue 3 + TypeScript**：负责界面与交互。Vue 用组件拆分页面；TypeScript 会在运行前检查常见的数据类型错误。
- **Element Plus**：提供表格、表单、弹窗、按钮等成熟控件，减少重复开发并保持界面风格统一。
- **Rust**：负责本地数据库、文件读写、备份恢复以及 Word / Excel 安全处理。Rust 的类型与内存安全检查适合处理重要题库数据。
- **SQLite**：一个保存在本机文件里的数据库，不需要安装数据库服务器，也不需要联网，适合单机离线软件。
- **Tiptap 3**：负责日常录题。新内容保存 Tiptap JSON，并继续保存 HTML 与纯文本兼容缓存；旧 HTML 题目可以直接打开，实际编辑时才升级。
- **canvas-editor**：负责试卷分页、排版和直接打印。原生排版 JSON 随试卷保存；题目变化时先保留旧排版，避免自动覆盖手工调整。
- **Rust OOXML DOCX 方案**：直接读取和生成 `.docx` 内部的 OOXML 文件，不依赖 Microsoft Word、LibreOffice，也不生成 PDF。

## 已完成的基础能力

- 12 个主要页面入口和第一版整体导航框架。
- 题库列表、搜索筛选、题目快速预览、题目录入与 SQLite 60 秒草稿保存；切页、关闭软件和版本冲突均有保护。
- 日常录题已切换到 Tiptap JSON V2；粗体、斜体、列表、图片、表格、上/下标和公式节点仍保留 HTML/纯文本兼容输出。
- 五种内置题型：单选、多选、填空、判断、简答；还可在题型管理中增加自定义题型。
- 回收站、Word / Excel 导入四步流程、手动选题和按标签候选题库随机抽题；批量导入审查页支持 SQLite 自动草稿、恢复/放弃和失败项保留。
- SQLite 数据库迁移、完整性检查、全文检索索引和真实题目增删改查命令。
- 学科、章节、标签的真实 SQLite 增删改查、关联保护和拖动排序。
- 试卷草稿、历史试卷和完整题目快照的真实 SQLite 保存、读取、复制与永久删除；使用行版本防止多窗口互相覆盖。
- 试卷排版已接入 canvas-editor：可编辑真实分页稿、保存原生排版 JSON、撤销/重做、插入分页符、缩放并直接打开系统打印流程。
- Word 模板的真实 SQLite 管理：安全导入、锚点分析、重命名、默认模板、文件回滚和墓碑删除。
- 旧数据库“副本迁移 → 校验 → 原子切换 → 自动回滚 → 保留旧库”的安全升级流程。
- W1 DOCX 安全读取、原生文件选择、公式片段识别、结构化诊断、模板锚点识别和受限底层导出模块。
- Word 导入中的 PNG/JPEG 图片会经过尺寸、容量、外部关系和路径安全检查，再按内容摘要写入受管资源目录；草稿、正式题目和试卷快照都会保存对应引用，重新打开时可恢复显示。
- `.tqb` 完整备份创建与校验：先生成 SQLite 一致性快照，再写版本化清单和逐文件 SHA-256；限制路径穿越、重复路径、符号链接、ZIP64 和压缩炸弹，并把真实记录显示在备份页面。
- `.tqb` 安全恢复闭环：受控复制与解压、候选数据库和全目录摘要复检、恢复前自动备份、重启切换、异常中断回滚、旧数据保留和恢复结果确认；数据库损坏时可使用“原目录隔离保留”的救援模式。
- 数据目录安全迁移：使用一致性数据库快照复制 `database/resources/templates/backup/export`，逐文件与整树摘要复检后通过独立引导配置在重启时切换；目标失败时继续使用原目录，旧目录永不自动删除。
- 完全重复和疑似重复检查：题目录入与 Word / Excel 批量导入都提供“跳过、覆盖、继续保留”三种明确选择；批量导入会在每次写入前重新检查，避免同一批次内漏检。
- 单实例运行、生产内容安全策略和后端富文本大小/危险代码限制。
- Windows x64 正式 Release 与中文 NSIS 单用户安装包已经生成；当前 `downloadBootstrapper` 安装方式会在缺少 WebView2 时联网下载运行库，不应当作完全离线安装包。窗口最小化、最大化、关闭、拖动和子窗口销毁权限已补齐。
- Windows 桌面端支持签名自动更新：启动后延迟检查，也可在“系统设置 → 关于软件”手动检查；用户确认后才下载并安装，网络失败不影响本地使用。
- 统计页面读取真实题库数据计算总量、近期新增/使用和分类分布；备份页面只在后端真正完成 `.tqb` 写入与复检后报告成功，不再显示随机进度或虚构文件大小。
- 已保存试卷可从组卷页或历史试卷导出为真实 `.docx`：软件会校验试卷版本、受管模板、`ZT_QUESTIONS` 锚点和输出路径，并在文件重新打开复检成功后才报告完成；支持受管图片、原生 Word 表格和可编辑 OMML 公式，不支持的嵌套表格、外链图片或原始 OOXML 会明确提示位置并拒绝导出。
- 题库可导出为 Word 或 Excel：Word 包含全部有效题目的分类、题干、选项、答案、解析、标签及受支持的富内容；Excel 每题一行，导出文字字段和时间等元数据，不在单元格中嵌入图片、表格或公式，也不设置分值。
- 题库可从 `.xlsx` 批量导入：支持下载标准模板、选择工作表，并识别题型、学科、章节、题干、分列或合并选项、答案、解析和标签；当前题库 Excel 导出文件可直接重新导入。导入结果进入与 Word 相同的逐题校验、分类和重复检查流程。
- 随机抽题由 SQLite 后端直接按学科、多个章节、任一/全部标签和右侧已选题目统计候选；抽取时只读取最终命中的完整题目，不再把全部候选富文本传到前端。手动候选支持真实分页，编辑页可以在同题型和当前筛选范围内替换题目并保留原位置。
- 当前新建试卷统一保存为手动组卷模式；数据库继续读取旧版自动组卷的 `generation_config_json`，仅用于保证历史试卷能够打开、复制和按原题型范围替换题目。
- 历史试卷页面会按 100 份一页读取完整列表（最多 5 万份安全上限），不再只取前 500 份；读取过程中若总数或顺序变化会要求重新加载，避免静默漏掉记录。
- 题库批量编辑已接入原子事务：可成对修改学科/章节、追加/替换/删除标签和重置最近使用状态；任意题目版本冲突或分类无效时整批撤销。
- 浏览器演示模式会醒目标明“不读写真实文件”，并关闭 Word / Excel 导入、模板、备份恢复、目录迁移和真实导出等桌面操作，方便不安装桌面版时安全检查界面。

## 当前限制与暂不纳入范围

- Word 富内容导出不处理嵌套表格、外链图片、缺少 LaTeX 数据的公式节点或未经结构化转换的原始 OOXML；软件会列出具体题目并拒绝导出，不会静默丢失内容。
- Excel 导入当前只读取 `.xlsx` 中的文字和值，不导入浮动图片、复杂表格或公式对象；公式单元格只读取文件中已经保存的显示值。旧版 `.xls` 和带宏的 `.xlsm` 需要先另存为 `.xlsx`。
- 按当前产品决定不提供独立的 Word 导入历史查询页；只保留正在审查批次的可恢复草稿，完成或放弃后不形成长期导入记录。
- 新选择、粘贴和从 WPS 带入的图片已经受管存储并按内容去重；旧版本遗留图片尚不主动批量迁移，因此无引用资源永久清理继续保持关闭。
- 在 Windows Sandbox、虚拟机或一次性测试账户中完成首次安装、覆盖安装、单实例启动，以及卸载时“保留数据/删除受管数据”两条路径的隔离验收；不要用唯一一份真实题库直接测试删除流程。

## 开发环境前置条件

1. Node.js 20.19+、22.12+ 或 24.x（本机当前为 24.x）。
2. pnpm 11.19.0（版本已记录在 `package.json`）。
3. Rust stable（MSVC 工具链）。
4. Microsoft Visual Studio 2022 Build Tools，并勾选“使用 C++ 的桌面开发”。
5. Microsoft Edge WebView2 Runtime（Windows 10/11 通常已经安装）。

“Build Tools”不是用来写界面的软件，而是把 Rust 最终连接成 `.exe` 的微软编译组件。缺少它时，前端网页仍能运行，但无法生成真正的 Windows 桌面程序。

## 常用命令

首次获取项目，在 PowerShell 中执行：

```powershell
git clone https://github.com/BBkjdayup/BCTK.git tktiku
cd tktiku
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm dev` 只启动浏览器预览。启动真实桌面窗口：

```powershell
pnpm tauri dev
```

运行前端检查和单元测试：

```powershell
pnpm lint
pnpm test
pnpm build
```

修改 `package.json` 中的版本号后，先同步并检查其他应用清单：

```powershell
pnpm version:sync
pnpm version:check
```

生成不需要官方更新签名私钥的本地 Windows 安装包：

```powershell
pnpm build:installer
```

该构建仅关闭更新签名产物的生成，保留现有功能、应用标识及更新服务配置。分发自己的修改版前，按[开源构建说明](docs/open-source.md)配置独立的应用标识、服务和签名公钥。

由持有官方发布密钥的维护者生成签名安装包、签名文件和 `latest.json`：

```powershell
pnpm release:update
```

签名发布流程、密钥保管、服务器目录和回滚要求见 [`docs/automatic-updates.md`](docs/automatic-updates.md)。`0.1.74` 是第一版带更新器的客户端，旧版用户需要手工安装一次，之后才能在软件内升级。

正式包默认连接 `https://api.tktiku.cn`。如需生成连接其他测试环境的内部包，可在编译时覆盖 API 地址：

```powershell
$env:ZHITIKU_CLOUD_API_URL = "https://test-api.example.cn"
pnpm tauri build
```

覆盖地址必须使用部署了有效证书的 HTTPS 域名；只有回环地址允许 HTTP。未设置环境变量时使用正式云服务地址，断网或云授权到期均不影响软件允许范围内的本地功能。

成功后主要得到两个文件：

- `src-tauri/target/release/zhitiku-desktop.exe`：可执行主程序，主要用于开发和排查。
- `src-tauri/target/release/bundle/nsis/TK试题题库_<版本号>_x64-setup.exe`：给普通用户双击安装的中文 Windows 安装包。

各版本的用户可见变化见 [`CHANGELOG.md`](CHANGELOG.md)。

编辑器数据流、兼容策略和发布边界见 [`docs/编辑器与组卷架构.md`](docs/编辑器与组卷架构.md)。本项目原创代码采用 [MIT 许可证](LICENSE)；第三方组件保留各自许可，见 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)。

安装与首次使用的非技术说明见 [`docs/Windows安装与首次使用.md`](docs/Windows安装与首次使用.md)。

## 数据安全原则

- 题库默认只保存在本机，不上传云端。
- 数据库使用事务、外键约束和完整性检查，避免一次操作只写入一半。
- 回收站提醒期限可在设置中调整（默认 30 天），到期只提醒，不自动悄悄删除。
- 更换数据目录时采用“复制 → 校验 → 切换 → 保留旧数据”的流程。
- Word 文件会拒绝宏、ActiveX、外部关系、路径穿越和异常压缩包等高风险内容；Excel 文件会限制扩展名、文件大小、部件数、解压体积、工作表数、行列数和单元格长度。
- 备份与恢复完成前不会直接覆盖唯一一份有效数据。

## 目录说明

- `website/`：TK试题题库官网，部署于现有阿里云 ECS；开发使用 `pnpm website:dev`，构建使用 `pnpm website:build`。配置与发布见 [`docs/website-deployment.md`](docs/website-deployment.md)。
- `src/`：Vue 界面、状态管理和桌面命令调用。
- `src-tauri/src/`：Rust 本地业务、SQLite 和 DOCX 处理。
- `src-tauri/migrations/`：数据库版本升级脚本。
- `src-tauri/tauri.conf.json`：Windows 窗口与打包配置。
