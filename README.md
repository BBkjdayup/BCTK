# -
TK试题题库是一款面向教师个人和教育机构的 Windows 桌面题库与组卷软件，以本地离线使用为核心，数据默认保存在本机。支持富文本与数学公式编辑、Word/Excel 批量导入导出、学科/章节/标签分类检索、重复题检测、手动选题与随机抽题、试卷分页排版及打印，并提供题库统计、回收站、备份恢复和数据目录迁移功能。基于 Tauri 2、Vue 3、TypeScript、Rust 和 SQLite 构建，结合 Tiptap 与 canvas-editor 实现录题和试卷编辑，Word 文档处理无需依赖 Microsoft Office。源码包含桌面客户端、官网、测试及授权工具，采用 MIT 许可证，欢迎教师和开发者共同改进。
