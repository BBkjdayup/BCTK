# 小程序试卷富文本约定

桌面发布转换、云端富文本校验和小程序媒体替换共同维护以下约定。修改时同时检查三个端的回归，不能只调整其中一个白名单。

| 内容 | 发布行为 |
| --- | --- |
| 普通表格 | 保留 table、thead、tbody、tfoot、tr、td、th 的结构和文本 |
| 横向 / 跨行合并 | 仅在 td、th 上保留 colspan、rowspan；属性值为不带前导零、空白或符号的十进制整数，范围 1–1000 |
| 缺省合并属性 | 不添加属性，保持普通单元格 |
| 非法或超范围合并值 | 桌面预检查和发布转换报错，标明题号及字段；云端也拒绝，不自动改成 1 |
| 表头和表尾分组 | 保留分组边界，避免改变跨行合并的含义 |
| 表格里的图片或公式 | 沿用受保护的 tkasset 资源；小程序替换图片地址时保持合并属性 |
| 事件、外部链接和任意样式 | 不随桌面发布输出；云端仍拒绝未允许的属性及外部图片地址 |

1–1000 是本项目的安全边界，不是微信平台公布的限制。`rowspan="0"` 等特殊值不在本项目支持范围。此约定保留表格结构，不承诺像素尺寸或任意 CSS 排版与桌面完全一致。

[微信官方 rich-text 文档](https://developers.weixin.qq.com/miniprogram/dev/component/rich-text.html)将 td、th 的 colspan 和 rowspan 列为受信任属性。2026-10-20 已核对该文档；真实客户端的显示效果仍应纳入发布验收。

自动验证覆盖桌面转换与预检查、云端属性校验和真实数据库发布/练习接口、小程序图片占位与加载。跨端样例均包含两列表头、跨两行的图片单元格及表尾，并检查非法数值和事件属性被拒绝。

发布顺序：先部署支持合并属性的云服务，再发布桌面更新；旧桌面生成的普通表格仍可被新服务接受。旧云服务会拒绝新桌面带合并属性的试卷，不能只发桌面安装包就宣布此修复已上线。

已经发布并丢失合并属性的快照无法从云端自动重建。需要从保留原表格的本地试卷重新保存为新版本或新试卷，再发布。云端仍禁止同一版本号对应不同内容；已有练习继续保留原快照，不重写学员历史记录。
