# 历史试卷保存与导出修复

修复日期：2026-09-10。

原来首次保存后，编辑区一直保留原试卷 ID；改标题、返回选题或清空重组后再保存，都会更新同一条记录并替换题目快照。历史页导出前也会把导出标题和内容模式写回原卷。

现在草稿仍可原位保存。第一次归档后，修改内容再保存会产生新试卷和新题目 ID，并同步重映射画布引用；原历史试卷不变。无修改的重复保存不新增记录。保存期间继续编辑的内容仍保留在编辑区并标为未保存，导出调用只得到本次实际保存的快照。失败时保留当前编辑内容。切换试卷和退出前的保存共用这一规则。

SQLite 保存命令和浏览器演示后端均拒绝覆盖已归档记录，错误码为 `PAPER_ARCHIVE_IMMUTABLE`；草稿归档和明确删除仍按原有流程执行。没有修改已发布的数据库迁移。

导出请求新增可选的 `title` 和 `contentMode`，只改变本次导出快照。历史页导出已有归档不调用保存；草稿导出先归档，组卷页未保存的编辑先保存。导出模板始终是本次导出选项。Rust 仍验证试卷版本、标题长度、内容模式、模板、资源和路径，导出设置不更新试卷行。省略新字段的调用继续沿用试卷原有设置。

回归测试覆盖清空重组、草稿归档、重复点击、写入失败、排版引用、新增归档时的并发编辑、退出前保存、绕过界面覆盖、SQLite 事务回滚及导出快照隔离。测试使用合成数据；本次不恢复既往被覆盖的数据，不安装或发布更新。
