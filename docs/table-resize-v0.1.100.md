# 录题表格尺寸调整（0.1.100）

本版增加表格整体大小、列宽和行高调整。点击表格内任意单元格后，右下角出现整体拖动点，列和行的分隔线可拖动；表格上方提供“适应页面”和“恢复默认”。文字字号不随表格大小变化，原有表格文字编辑和增删行列继续使用。

## 保存与兼容

- 拖动期间仅更新显示，松手后以一次编辑保存，支持撤销与重做。其他指针、未移动的点击、取消拖动、窗口失焦不会写入尺寸。
- 总宽度存入 table.width，列宽存入单元格 colwidth，最小行高存入 tableRow.minHeight。HTML 同时保存 data-table-width、colgroup 和 data-row-min-height，供题目预览、组卷和 Word 导出使用。
- 行高是最小高度，文字、公式、图片过多时允许自动撑开。表格宽度限制在当前编辑区域内，页面缩放不改变拖动比例。
- 无尺寸信息的旧表格仍可直接编辑，无数据库结构迁移。Word 导入新增读取 tblW、tblGrid、trHeight，旧版未完成的导入草稿提示重新导入。
- Word 导出写入真实表格列网格与最小行高，不采用图片或整体变换。原有纵向合并单元格和嵌套表格的 Word 导出限制保持现状。
