# 桌面授权与云授权说明

## 产品规则

- 桌面授权和云授权相互独立。
- 软件首次启动时自动开始 15 天桌面专业版免费试用；试用到期后还有 15 天宽限期。
- 免费试用及宽限期内开放桌面专业版功能；两段期限都结束后，软件进入“基础桌面模式”。
- 正式桌面许可证的默认宽限期同样为 15 天；许可证及宽限期都结束后进入“基础桌面模式”。
- 基础桌面模式保留题库浏览、搜索、手动单题录入与编辑、分类标签管理、备份恢复和数据迁移。
- 基础桌面模式每份试卷最多 10 题，可创建任意数量的试卷；已有超过 10 题的旧试卷不会被截断，但必须删减到 10 题以内才能再次保存。
- 基础桌面模式关闭 Word/文档式批量导入、题库与试卷文档导出、打印以及系统“打印为 PDF”。
- 桌面专业版解锁批量导入、不限题量组卷、DOCX/XLSX 导出和打印。
- 当前正式交付不包含云订阅、题目云同步和网页版。如后续独立上线，云订阅只控制云同步和网页版，不改变本机桌面功能授权。

## 安全边界

- 软件只内置 Ed25519 公钥，不包含签发私钥。
- 每台电脑第一次运行时会生成独立设备密钥；Windows 使用当前用户的 DPAPI 保护该密钥。
- `.tkreq` 授权申请包含设备公钥、设备编号、软件版本和随机校验信息，不包含题库内容。
- `.tklic` 许可证使用签发私钥签名，并绑定申请设备。用户修改许可证内容或复制到另一台电脑都会校验失败。
- 本机记录“已见过的最晚时间”，系统时间回拨时不会把已过期许可证恢复为有效状态。
- 免费试用从首次启动起算；设备标识、起算时间和可信时钟使用当前 Windows 用户的 DPAPI 加密，并保存在普通卸载不会清除的最小授权状态目录中。即使卸载时选择删除题库和设置，重新安装也不会自动重置试用期。
- 离线许可证文件属于可删除的本机设置；卸载时选择删除数据会移除该文件，但不会改变许可证本身的设备绑定和有效期，重装后可重新导入原许可证。
- 离线授权无法绝对阻止专业逆向人员修改程序本身；此方案的目标是阻止普通复制、伪造许可证和简单回拨时间。

## 私钥管理

签发私钥必须放在项目目录和任何云同步目录之外，只允许授权负责人访问，并至少制作一份离线加密备份。不得把私钥发给客户、提交到 Git、放入安装包或截图公开。

当前软件内置公钥位于 `src-tauri/licensing_public_key.txt`。更换签发密钥后必须同步替换公钥、更新密钥编号并重新发布软件；旧许可证不会自动兼容新密钥。

## 给客户签发许可证

1. 客户在“系统设置 → 桌面授权”中点击“生成离线授权申请”，把 `.tkreq` 文件发给授权负责人。
2. 授权负责人打开桌面上的 `TK试题题库授权工具\TK试题题库授权工具.exe`，依次选择客户的 `.tkreq` 和离线保管的签发私钥。
3. 填写客户名称、到期时间和新的 `.tklic` 保存位置，核对设备编号后点击“验证并签发许可证”。工具会验证申请文件签名，并检查私钥是否与当前软件内置公钥匹配。
4. 只把生成的 `.tklic` 发给客户。客户在同一页面点击“导入许可证”，验证成功后立即生效，不需要重启或联网。

图形工具可用下面的命令重新构建，默认输出到 `tools/license-issuer/dist`；也可以通过 `-OutputDirectory` 指定内部交付目录。构建结果不会包含私钥。

```powershell
.\tools\license-issuer\build.ps1
```

如果图形工具不可用，可以使用下面的命令行备用流程。先在 PowerShell 中把到期日期换成 Unix 毫秒时间戳：

   ```powershell
   $expires = [DateTimeOffset]::Parse('2027-08-21T23:59:59+08:00').ToUnixTimeMilliseconds()
   ```

然后在项目的 `src-tauri` 目录执行签发命令：

   ```powershell
   cargo run --locked --example license_admin -- issue "D:\离线密钥\desktop-license-prod-2026.key" "D:\授权申请\客户.tkreq" "D:\待发送\客户.tklic" "客户名称" $expires
   ```

## 后续云授权接入（当前未发布）

仓库中的云账号与同步代码是后续开发基础，不属于当前 Windows 正式交付。未来若上线，云服务应使用独立账号、订阅记录和服务端令牌；桌面端可以读取云订阅状态，但不得用云订阅覆盖本地 `desktop` 授权状态，最终功能权限继续由 `LicenseOverview.capabilities` 汇总后提供给界面。
