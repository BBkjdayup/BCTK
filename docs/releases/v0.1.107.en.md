# v0.1.107 source notes

This update brings the public source from v0.1.105 to v0.1.107. The scope remains the Windows desktop client, product website, and web-admin frontend. The independent public history, MIT license, and community documents are preserved.

## Main changes

- Add subject → chapter → unit classification, with optional units. Question editing, filters, batch edits, imports and exports, saved papers, and random draws support unit information.
- Add “all tags” and “any tag” matching for manual paper assembly. Search, question type, and tag filters stay on one row.
- Discard late random-draw results after cancellation, dialog closure, or switching papers.
- Track candidate-count requests separately from draw submission. Prevent duplicate submissions during a draw or count confirmation, and report the actual number of questions added.

See the [changelog](../../CHANGELOG.md) for details. New components, regression tests, and database migrations are included. The website and admin frontend remain under `website/`.

## Data upgrade and rollback

All 26 SQLite migrations are included, with the new `0026_optional_units.sql`. Upgrading to schema 26 preserves existing subjects, chapters, and questions. Existing questions have no assigned unit and do not require reclassification.

Keep a copy of the original database or a full backup before upgrading. Older applications cannot open a database upgraded to schema 26. To roll back to v0.1.105, use the database or backup saved before the upgrade; edits made after upgrading will not be present in that older backup.

## Public scope and builds

The standalone backend, mini-program client, internal acceptance records, release tooling, and production credentials are excluded. Optional mini-program publishing still requires compatible services and account permissions.

`pnpm build:installer` retains the ordinary installer build without the official updater private key. `pnpm release:update` continues to require the complete maintenance workspace and official release quality gates; it cannot perform official signing from a standalone public clone. See the [open-source notes](../open-source.md) before distributing modified builds.

This GitHub operation synchronizes source only. Official Windows installers are available from the [download page](https://tktiku.cn/#download).
