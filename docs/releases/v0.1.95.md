# v0.1.95 源码说明

发布日期：2026-09-27

本次将桌面端 v0.1.95 的源码更新到公开仓库。此标签仅标识源码，不代表已发布同版本的 Windows 安装包；正式安装包版本以[官网](https://tktiku.cn/#download)为准。

## 主要变化

- 小程序管理可移除已授权成员，撤销题库访问并释放其占用的免费或付费名额；练题记录保留。
- 套餐暂停或到期的已授权成员继续显示在“已授权”列表，状态会说明当前无法访问的原因。
- 名额恢复后，可对未占用名额的成员重新授权。

小程序成员操作需要兼容的配套云服务。本仓库只包含桌面客户端和网页管理端前端，不包含独立云服务端；发布此源码不代表在线服务已同步升级。完整逐版本变化见 [CHANGELOG.md](../../CHANGELOG.md)。
