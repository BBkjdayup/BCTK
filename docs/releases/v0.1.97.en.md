# v0.1.97 source notes

Published: 2026-09-29

This update brings desktop source changes from v0.1.96 through v0.1.97 to the public repository. v0.1.96 was an intermediate version that was not released separately. The tag identifies source code only; it does not mean a Windows installer with the same version has been published. Check the [official download page](https://tktiku.cn/#download) for the installer version.

## Highlights

- Improved mathematical Word import, preserving roots, fractions, superscripts, and subscripts in question stems, options, and explanations.
- Fixed fill-in lines made of underlined spaces disappearing during import. Underlined answers containing text are still recognized as written.
- Reduced incorrectly split questions, misplaced option images, and answers or explanations assigned to the wrong part of a question.
- Unfinished Word import drafts made with an older parser prompt the user to import again rather than reuse stale parsing results.

See [CHANGELOG.md](../../CHANGELOG.md) for the complete version history (Chinese).

## Verification and scope

- Version consistency, ESLint, and TypeScript checks passed. The full frontend suite ran with two workers: 65 test files passed, 1 skipped; 368 tests passed, 6 skipped.
- A full Rust library test rerun passed: 207 tests passed, 3 ignored; formatting and strict Clippy checks passed.
- Production builds passed for the desktop frontend, product website, and web-admin frontend.

Automated checks do not replace Windows installation, real-document compatibility, printing, or backup/restore testing. GitHub's Source code archives are not installers. Read the [open-source build notes](../open-source.md) before independently building or distributing a modified application.
