# v0.1.94 source notes

Published: 2026-09-25

This update brings desktop source changes from v0.1.89 through v0.1.94 to the public repository. The tag identifies source code only; it does not mean a Windows installer with the same version has been published. Check the [official download page](https://tktiku.cn/#download) for the installer version.

## Highlights

- Improved Word question import, including fewer false option matches in question stems, answers, and explanations, plus broader MathType, WPS formula, and WMF image support.
- Added batch tag adjustments in import review and clearer import error messages with recovery guidance.
- Added background download of signed updates with installation after a safe application close; manual update checks can still install immediately.
- Corrected the display and explanation of the permanently free mini-program seat in the desktop and web-admin interfaces.

See [CHANGELOG.md](../../CHANGELOG.md) for the complete version-by-version history (Chinese).

## Verification and scope

- Frontend checks: 65 test files passed, 1 skipped; 363 tests passed, 5 skipped.
- Rust library tests: 200 passed, 3 ignored; formatting and strict Clippy checks passed.
- Production builds passed for the desktop frontend, product website, and web-admin frontend.

Automated checks do not replace Windows installation, real-document compatibility, printing, or backup/restore testing. GitHub's Source code archives are not installers. Read the [open-source build notes](../open-source.md) before independently building or distributing a modified application.
