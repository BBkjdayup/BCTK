## 下载哪个文件

前往 [v0.1.83 发布页](https://github.com/BBkjdayup/BCTK/releases/tag/v0.1.83)，在 Assets 中选择：

| 文件 | 用途 |
| --- | --- |
| `BCTK_0.1.83_windows_x64-setup.exe` | Windows 10 / 11 x64 安装包 |
| `BCTK_0.1.83_windows_x64-setup.exe.sig` | 安装包的 Tauri 更新签名，供维护者核验；普通安装不需要另行打开 |

## 使用范围

- 当前程序保留 15 天专业版试用和 15 天宽限期，之后进入基础模式；基础模式每份试卷最多 10 题，并关闭批量导入、文档导出和打印等功能。
- 源码采用 MIT 许可，第三方组件遵循各自许可；源码许可不自动改变安装包的默认授权行为。
- 安装程序仅为当前用户安装。缺少 WebView2 时会联网下载运行环境，不能保证在所有电脑上完全离线安装。
- Windows 可能显示“未知发布者”；请从本仓库发布页下载并核对摘要。
- 独立云服务端不包含在本仓库，云同步需要配套服务与账号权限。客户端仍使用原有更新及服务配置，本次 GitHub 发布没有更新运营中的服务或更新清单。
- 复杂 Word / Excel 内容存在兼容边界，详见 [README](../../README.md#文件兼容说明)。

升级或迁移前请创建 `.tqb` 完整备份。安装和数据目录说明见 [Windows 安装与首次使用](../Windows安装与首次使用.md)。使用问题与改进建议欢迎提交到 [Issues](https://github.com/BBkjdayup/BCTK/issues)。
