# v0.1.97 源码说明

发布日期：2026-09-29

本次将 v0.1.96 至 v0.1.97 的桌面端源码更新到公开仓库；v0.1.96 是未单独发布的中间版本。此标签仅标识源码，不代表已发布同版本的 Windows 安装包；正式安装包版本以[官网](https://tktiku.cn/#download)为准。

## 主要变化

- 改进数学 Word 试卷导入，保留题干、选项和解析中的根式、分式、上标和下标，减少公式显示错误。
- 修复带下划线的空格被压缩，导致填空横线消失的问题；已填写的下划线答案仍按原文字识别。
- 减少题目误拆、选项图片错位及答案和解析归属错误。
- 旧版未完成的 Word 导入草稿会提示重新导入，避免沿用旧解析结果。

完整逐版本变化见 [CHANGELOG.md](../../CHANGELOG.md)。
