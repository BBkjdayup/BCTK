# v0.1.88 发布说明

发布日期：2026-09-20

v0.1.88 是公开仓库从 v0.1.83 更新后的首个源码版本，汇总 v0.1.84 至 v0.1.88 的桌面端变化。

## 主要变化

- 桌面本地功能改为免费使用，移除试用期、设备绑定、离线许可证和每份试卷 10 题的限制。
- 移除旧题库云同步、冲突处理和云服务地址配置；本地题库继续保存在本机。
- 加强题目重复识别、公式与图片身份判断、试卷历史保存保护和关闭前未保存内容保护。
- 增加题库 Word / Excel 导出、设置工作区整理及多项导入导出兼容修复。
- 增加可选的小程序管理入口，可发布已保存试卷、管理邀请码与成员、查看跨电脑发布记录。
- 小程序发布支持受管 PNG/JPEG 图片及由公式渲染的图片；在线功能需要兼容账号服务与套餐权限。
- 增加客服开通 / 续费入口，并支持从服务端读取维护者提供的联系资料。

## 数据与兼容

- 升级不会删除题目、试卷、图片、模板或备份。
- 旧授权与同步表继续保留在历史迁移中，以保证已有数据库的迁移校验；当前业务不再使用这些流程。
- 正式安装包主要面向 Windows 10 / 11 x64。
