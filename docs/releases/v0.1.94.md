# v0.1.94 源码说明

发布日期：2026-09-25

本次将 v0.1.89 至 v0.1.94 的桌面端源码更新到公开仓库。此标签仅标识源码，不代表已发布同版本的 Windows 安装包；正式安装包版本以[官网](https://tktiku.cn/#download)为准。

## 主要变化

- 改进 Word 试题导入：减少题干字母、答案和解析被误判为选项的问题；扩展 MathType、WPS 公式和 WMF 图片兼容性。
- 导入核对页支持批量调整标签，导入失败时给出更清楚的原因和处理建议。
- 更新器支持后台下载签名更新，并在安全关闭软件后安装；手动检查更新仍可选择立即安装。
- 修正小程序管理页和网页管理端的永久免费名额显示与说明。

完整逐版本变化见 [CHANGELOG.md](../../CHANGELOG.md)。
