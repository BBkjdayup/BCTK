# v0.1.105 源码说明

本次将公开源码从 v0.1.97 更新到 v0.1.105，范围为 Windows 桌面客户端、官网和网页管理端前端。延续公开仓库原有提交历史；独立云服务、小程序客户端、内部验收材料和生产凭据不在公开范围内。

## 主要变化

- 常用题库筛选可以命名保存和复用。
- 单题保留最近 50 个历史版本及图片引用，恢复时生成新版本。
- 普通批量编辑支持整批撤销；检测到后续修改、使用或删除时停止撤销。
- 录题图片支持稳定的等比例缩放；表格支持调整总宽、列宽和行高，并保留到预览及 Word 导出。
- 改进 Word 选项、公式及历史模板兼容，补充富内容检查和取消处理。
- 改进启动加载和旧数据升级，修复备份恢复中断后的继续恢复。
- 桌面小程序管理增加学情报告与题目反馈，需配套兼容云服务和账号权限。

SQLite 迁移和本地修订的 `tex2word-math` 源码、测试及许可证随本次源码一并保留。更多变化见 [变更日志](../../CHANGELOG.md)。

## 构建边界

`pnpm build:installer` 继续提供无需官方更新私钥的普通安装包构建。`pnpm release:update` 保留完整维护工作区的质量门禁，不能从独立公开克隆执行官方签名发布。修改版独立分发要求见 [开源说明](../open-source.md)。

本次 GitHub 操作是源码同步，不安装软件、不部署官网或云服务，也不上传小程序。正式 Windows 安装包以[官网下载页面](https://tktiku.cn/#download)为准。

## 本次公开副本验证（2026-11-06）

- 按锁文件安装依赖，版本一致性、ESLint 和 TypeScript 检查通过。
- 前端测试 421 项通过、7 项跳过；桌面前端、官网、网页管理端构建通过。
- Rust 格式检查和离线锁定依赖元数据解析通过；本轮未重跑完整 Rust 原生测试或构建安装包。
- 公开源码文件、25 份 SQLite 迁移和锁文件已逐项核对；已知凭据规则扫描未发现匹配项。

本轮使用 Node.js 24.21.0、pnpm 11.25.0，仓库保留既有 pnpm 11.16.0 固定声明。桌面构建仍提示部分压缩后分块超过 500 kB；该提示未阻止构建。以上检查不替代安装、真实题库升级、打印或在线服务验收。
