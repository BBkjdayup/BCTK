# v0.1.95 source notes

Published: 2026-09-27

This update brings the v0.1.95 desktop source to the public repository. The tag identifies source code only; it does not mean a Windows installer with the same version has been published. Check the [official download page](https://tktiku.cn/#download) for the installer version.

## Highlights

- Owners can remove authorized mini-program members, revoking question-bank access and releasing their free or paid seats while preserving practice history.
- Authorized members affected by a paused or expired plan stay in the authorized list, with a status explaining their current lack of access.
- Members without a seat can be authorized again when capacity becomes available.

Mini-program member actions require a compatible cloud service. This repository contains the desktop client and web-admin frontend, not the standalone cloud backend. Publishing this source does not imply that the live service has been upgraded. See [CHANGELOG.md](../../CHANGELOG.md) for the full version history (Chinese).

## Verification and scope

- Production builds passed for the desktop frontend, product website, and web-admin frontend; Rust formatting passed. No Rust business code changed in this version, so Rust library tests were not rerun.
