# v0.1.107 源码说明

本次将公开源码从 v0.1.105 更新到 v0.1.107，范围仍为 Windows 桌面客户端、官网和网页管理端前端。保留独立的公开提交历史、MIT 许可证及社区文档。

## 主要变化

- 新增“科目 → 章节 → 单元”三级分类，单元可选。录题、筛选、批量编辑、导入导出、历史试卷及随机抽题支持单元信息。
- 手动组卷支持“全部标签”或“任一标签”筛选，搜索、题型及标签筛选保持单行。
- 随机抽题在取消、关闭对话框或切换试卷后，不再把迟到的结果加入当前试卷。
- 候选题数量统计与抽题提交分别维护状态；抽题和数量确认期间阻止重复提交，并按实际新增题数反馈结果。

更多变化见 [变更日志](../../CHANGELOG.md)。新增组件、回归测试和数据库迁移随源码同步；官网及管理前端继续保留在 `website/`。

## 数据升级与回退

本版包含全部 26 份 SQLite 迁移，新增 `0026_optional_units.sql`。升级到 schema 26 时保留已有分类及题目，旧题默认未分单元，无需重新分类。

升级前请保留原题库或完整备份。旧程序不能直接打开已升级到 schema 26 的题库；回退到 v0.1.105 应使用升级前保留的原库或备份，升级后的新增和编辑不会出现在旧备份中。

## 公开范围与构建

独立云服务、小程序客户端、内部验收资料、发布工具及生产凭据不在本仓库内。可选的小程序发布功能仍需要兼容服务和账号权限。

`pnpm build:installer` 保留普通安装包构建入口，无需官方更新私钥。`pnpm release:update` 继续要求完整维护工作区与正式发布质量门禁；独立公开克隆不能执行官方签名发布。修改版分发要求见 [开源范围与构建说明](../open-source.md)。

本次 GitHub 操作仅同步源码。正式 Windows 安装包以[官网下载页面](https://tktiku.cn/#download)为准。
