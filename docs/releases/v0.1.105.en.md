# v0.1.105 source notes

This update brings the public source from v0.1.97 to v0.1.105. It includes the Windows desktop client, product website, and web-admin frontend while preserving the existing public commit history. The standalone backend, WeChat mini-program client, internal acceptance records, and production credentials remain outside this repository.

## Main changes

- Save and reuse named question-bank filters.
- Keep up to 50 versions of each question, including image references; restoring creates a new version.
- Undo a batch edit as one operation, with checks for subsequent edits, use, or deletion.
- Resize images reliably and preserve table width, column widths, and row heights through preview and Word export.
- Improve Word option parsing, formula and legacy-template compatibility, rich-content checks, and cancellation.
- Improve startup and legacy-data upgrades, including recovery after an interrupted backup restore.
- Add teacher learning reports and question feedback to desktop mini-program management, requiring compatible services and account permissions.

The update includes SQLite migrations and the locally patched `tex2word-math` source, tests, and license. See the [changelog](../../CHANGELOG.md) for details.

## Build boundaries

`pnpm build:installer` builds a regular installer without the official updater private key. `pnpm release:update` retains the official maintenance workspace's quality gates and cannot perform official signing from a standalone public clone. See the [open-source notes](../open-source.md) before distributing a modified build.

This GitHub update synchronizes source only. It does not install the application, deploy services, or upload the mini-program. Official Windows installers are available from the [download page](https://tktiku.cn/#download).
