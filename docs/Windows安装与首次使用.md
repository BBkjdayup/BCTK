# Windows 安装与首次使用

## 安装哪个文件

普通用户请前往 [GitHub Releases](https://github.com/BBkjdayup/BCTK/releases/tag/v0.1.83)，在 Assets 中下载并双击：

`BCTK_0.1.83_windows_x64-setup.exe`

GitHub 自动生成的 Source code 是源码压缩包，不是安装程序。开发者自行构建的安装包位于 `src-tauri/target/release/bundle/nsis/`，文件名为 `TK试题题库_<版本号>_x64-setup.exe`。

这是 64 位 Windows 中文联网引导安装包。若电脑已经安装 WebView2，安装时不会重复下载；若缺少 WebView2，安装程序会联网下载运行环境。安装完成后，题库的本地功能可以离线使用。

## 安装步骤

1. 关闭正在运行的旧版教师题库软件。
2. 双击安装包，按中文向导完成安装。
3. 安装方式是“仅当前用户”，不会自动给电脑上的其他账户安装。
4. 从开始菜单或桌面快捷方式打开“TK试题题库”。

## Windows 显示“未知发布者”是什么意思

当前版本没有 Windows Authenticode 签名，所以 Windows 可能显示“未知发布者”或 SmartScreen 提示。这表示 Windows 无法确认发布者身份。请从本仓库的 GitHub Release 下载，并核对发布页及 `SHA256SUMS.txt` 中的 SHA-256；具体版本来源、签名状态和核验范围见 [v0.1.83 发布说明](releases/v0.1.83.md)。

## 数据保存在哪里

首次启动默认在当前用户“文档”目录创建 `教师题库` 文件夹，其中保存数据库、图片资源、模板、备份和导出文件。卸载软件前仍建议先在“数据管理”页面创建 `.tqb` 完整备份。

覆盖安装和软件内更新不会删除这个用户数据目录。正常卸载时：

- 不勾选删除选项：保留题库及本机设置，重新安装后可继续使用。
- 勾选“删除本机题库、设置和登录信息（保留试用校验记录）”：删除软件登记过的数据库、图片资源、模板、备份、导出、设置和云账号登录信息；数据根目录内不属于软件的其他文件会保留。
- 设备标识、试用起始时间和可信时钟属于防止重复试用所需的最小授权校验记录，会继续保留；卸载重装不会重新获得 15 天试用。用户主动导入的离线许可证随本机设置删除，重装后可再次导入原许可证。

升级到包含此修复的版本后，应至少成功启动一次，让软件登记当前实际数据目录。如果尚未登记或安全校验失败，卸载器会提示并保留题库，而不会猜测路径后强制删除。

卸载前仍应创建 `.tqb` 完整备份。首次安装、覆盖安装和两种卸载路径的最终验收应在 Windows Sandbox、虚拟机或一次性测试账户中完成，避免拿唯一一份真实题库做试验。

## 如何核对当前版本

通用安装说明不再硬编码某个旧版本的测试数量。每次发布应在对应的 GitHub Release 中记录版本、测试数量、安装包大小、SHA-256 和签名状态，并至少执行：

```powershell
pnpm install --frozen-lockfile
pnpm version:check
pnpm audit --prod --audit-level moderate
pnpm check
cd src-tauri
cargo test --locked --lib
cd ..
pnpm tauri build
```

当前打包配置生成一个 NSIS 安装包，不生成 MSI。未购买商业代码签名证书时，签名状态仍会显示 `NotSigned`。
